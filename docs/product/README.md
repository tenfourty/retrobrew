# Retrobrew product docs

These documents describe how Retrobrew behaves. They are the source of truth for behaviour; the code and its tests follow them, and other docs link here.

| Document | What it covers |
| --- | --- |
| [lean-coffee-rules.md](lean-coffee-rules.md) | The rules the host engine enforces: phases, commands, limits, votes, discussion, rehearsal boards, what each person sees, and every refusal message |
| [sync-protocol.md](sync-protocol.md) | The sync protocol: snapshots and relay bundles, the send budget, ordered and acknowledged commands, clocks, liveness, reconnecting, versioning and the accepted gaps |
| [mvp-screens.md](mvp-screens.md) | Every app screen and state for facilitators and participants, at phone and wide widths, with exact copy and the design-system components |
| [landing.md](landing.md) | The landing page and the `/lean-coffee/` guide: structure, copy, head metadata, the old-link redirect and the phone layout |

Each document ends with the open choices it made where the behaviour left room.
