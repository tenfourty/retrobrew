Votes shown as the sticker dots people press onto cards at a real Lean Coffee.

- Dots cycle `dot-1`, `dot-2`, `dot-3`. Each has a `dot-edge` ring so the yellow dot still reads on a white card.
- The viewer's own votes get an `ink` outline (`mine`).
- Party overlaps the dots and multiplies them like overprinted ink.
- Above `max` (default 6) the count is written next to the dots.
- `hidden` is for Show votes off before the discussion: only the viewer's own dots show, followed by "Votes hidden".
- Screen readers get "5 votes, 1 yours", or "Votes hidden, 1 yours".
