A single choice from a row of buttons: the nine timeboxes, the five extensions, the four vote allowances.

- A label above, then the buttons. The chosen one fills with `primary` and carries `aria-pressed="true"`, so the choice is never colour-only.
- Buttons share the width and wrap onto more rows on phones; each is a 44px tap target.
- Options can be disabled, with a hint that says why ("The allowance can go up but not down").
- Labels follow the product docs' length rules: "5 min", or "50 s" on a rehearsal board.
