The column heading mark that says which stage a topic is in.

- One per column, in the product docs' order: `ideas`, `todiscuss`, `discussing`, `discussed` (the state names; the column ids are `ideas`, `toDiscuss`, `discussing`, `discussed`).
- Business draws a small state-colour disc before the label; Party turns it into a filled pill in the state colour with `on-state-*` text.
- State is also carried by the label, so colour is never the only signal.
- `count` shows the number of topics.
