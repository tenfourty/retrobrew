An on/off setting: "Show votes", "Use real minutes", "Play the timer sound on this device".

- A `role="switch"` button whose own text is the label, so the whole row is a 44px tap target.
- On fills the track with `primary` and moves the thumb right; off leaves it `sunken` with the thumb left. The position is the signal as well as the colour.
- A hint, if there is one, sits under the label and describes the switch.
- Disabled switches keep their hint, which says why ("Votes always show once the discussion starts").
- Not to be confused with `ModeSwitch`, the Business/Party toggle.
