A Sheet that asks before a destructive or far-reaching action: resetting votes, ending the meeting, deleting a topic, backing up the meeting file.

- A title that asks the question ("End the meeting?"), a body of full sentences with full stops, then a row of buttons.
- Buttons in this order: any other action first (such as "Copy as text"), the danger action last but one, and ghost "Cancel" last.
- Escape and "Cancel" close it without acting. Never use the browser's own `confirm()`.
