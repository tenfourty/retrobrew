How many votes the viewer has left, as words and as empty and full dots.

- Sits in the top bar in the topics and discussion phases, next to the attendee count.
- `total` comes from the board's vote allowance; `used` is the viewer's spent votes.
- Reads "3 votes left", "1 vote left" or "No votes left".
- Spent votes become empty rings, so the number and the shape agree. The dots are decoration; the words carry the count.
