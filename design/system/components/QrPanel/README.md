The light ground a QR code sits on, so phones can scan it in every theme.

- `qr-ground` behind `qr-ink` modules: white and black in all four themes, whatever the mode.
- The code keeps its own 4-module quiet zone inside the panel; the panel adds no padding of its own.
- At least 240px square; 256px where it fits. The code is an `<svg role="img">` with an accessible name, such as "QR code for the meeting link".
